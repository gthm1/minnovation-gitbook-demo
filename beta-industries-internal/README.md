# Getting Started

Welcome to your Xmesh LoRaWAN documentation portal.

This space covers everything you need to get your Xmesh environmental monitoring deployment up and running, from initial setup through to ongoing API integration.

### What is Xmesh?

Xmesh is Minnovation's LoRaWAN sensor platform, used for long-range, low-power environmental and industrial monitoring. Your deployment is configured for **industrial environmental monitoring**.
