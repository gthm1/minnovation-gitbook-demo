# Troubleshooting

Common issues and fixes for your Xmesh deployment.

### Gateway shows offline

1. Check the gateway's network backhaul connection
2. Confirm the status LED is solid green, not blinking
3. Power-cycle the gateway
4. If still offline after 10 minutes, check your network firewall rules for outbound access

### Sensor readings missing or delayed

| Cause             | Fix                                                             |
| ----------------- | --------------------------------------------------------------- |
| Out of range      | Confirm sensor is within gateway's effective range              |
| Low battery       | Check battery status in the dashboard                           |
| Gateway buffering | Readings may be delayed up to 24 hours during connectivity loss |

### Still stuck?

Contact your account manager with the gateway or sensor ID and a description of the issue.
