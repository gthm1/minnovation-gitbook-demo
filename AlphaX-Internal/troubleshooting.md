# Troubleshooting

Common issues and fixes for your AlphaX Cloud integrations.

### Quick fixes

| Issue                          | Fix                                                          |
| ------------------------------ | ------------------------------------------------------------ |
| API returning 401              | Confirm your API key hasn't expired or been rotated          |
| Webhook not firing             | Check your endpoint returns a 200 response within 10 seconds |
| Integration shows disconnected | Re-authorize the integration from the dashboard              |

### Still stuck?

Contact your account manager with a description of the issue and any relevant error codes.
